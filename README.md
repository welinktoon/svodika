# Svodika

Приложение для Windows, которое записывает микрофон, звук компьютера и при
необходимости экран, а затем локально расшифровывает встречу с помощью Whisper.

## Установка

1. Откройте раздел
   [Releases](https://github.com/welinktoon/svodika/releases/latest).
2. Скачайте `MeetingRecorderSetup-*.exe`.
3. Запустите установщик. Права администратора не требуются.

Пока установщик не подписан цифровым сертификатом, Windows SmartScreen может
показать предупреждение. Проверьте, что файл скачан из репозитория
`welinktoon/svodika`, затем выберите «Подробнее» → «Выполнить в любом
случае». Подпись можно добавить в одном из следующих обновлений без
переустановки приложения вручную.

## Обновления

При запуске приложение проверяет последний стабильный GitHub Release. Если
доступна новая версия, появится выбор «Обновить» или «Позже». Перед запуском
установщика приложение обязательно проверяет опубликованную SHA-256 сумму.

Проверку также можно запустить вручную:
`Настройки` → `Приложение` → `Проверить обновления`.

## Возможности

- запись микрофона;
- запись экрана и системного звука в MP4;
- локальная расшифровка через faster-whisper;
- выбор и загрузка локальных моделей;
- импорт существующего аудиофайла;
- история, поиск, воспроизведение и повторная расшифровка;
- глобальные горячие клавиши и работа из системного трея;
- черновик текста во время записи;
- необязательная обработка расшифровки через OpenAI, OpenRouter или Codex CLI;
- светлая и тёмная темы.

Записи, настройки и база хранятся в
`%LOCALAPPDATA%\Svodika` и не удаляются при обычном
обновлении.

## Сборка из исходников

Нужны Windows 10/11, Python 3.12 и Inno Setup 6:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt -r requirements-build.txt
powershell -ExecutionPolicy Bypass -File .\scripts\build_windows.ps1 -SkipDependencyInstall
```

Готовые файлы появятся в `installer-output`:

- `MeetingRecorderSetup-X.Y.Z.exe`;
- `MeetingRecorderSetup-X.Y.Z.exe.sha256`.

Публикация тега `vX.Y.Z` запускает тесты, собирает установщик в GitHub Actions
и прикладывает оба файла к GitHub Release.

## Разработка

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt -r requirements-build.txt
python app_qt.py
python -m pytest -q
```

Основная расшифровка работает локально. Для облачных провайдеров нужны
соответствующие API-ключи. Улучшение через Codex использует установленный
официальный Codex CLI и вход пользователя.
